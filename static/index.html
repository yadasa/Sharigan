      Workflow guide
      1. Prepare a source. Use a 4–30 second video with audio. Depth + SAM replaces masked subjects. Face mesh guides expressions on the original video without depth or segmentation. Combined mode overlays tracking on the depth composite. Mesh modes require the optional worker and work best with one centered speaker.
      2. Review every frame. Check subject coverage, background spill, cuts and flicker. For mesh modes, also check the eyes, mouth and facial alignment. Listen to the pitched vocals. Reject bad guidance and repair the mask or prepare the source again.
      3. Map the references. Describe which person each reference replaces. Review the complete prompt before confirming a paid draft. A video identity supplies appearance, while the source supplies speech and motion.
      4. Review and export. Download the draft or approve a separate 1080p generation. Both preserve the original soundtrack. Switch between versions to compare them.
      If processing stops
      Open Recent transformations and select the job. Resume collection when a saved task ID is available. An uncertain submission without a task ID requires checking ModelArk before starting another transformation. Preparation is never restarted automatically.
      Preparation and generation use hosted services and may incur charges. Local setup checks do not verify your provider balance or access.
